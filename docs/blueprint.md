# **App Name**: Fantasio

## Core Features:

- Authentication: User authentication with secure login and registration.
- Real-time Feed: Real-time feed of posts from followed users.
- Post Creation: Ability to create and share posts with images and text.
- Engagement: Like and comment on posts.
- User Profiles: User profiles with followers and following.
- Direct Messaging: Direct messaging with real-time updates.
- AI Hashtag Suggestions: AI tool to suggest relevant hashtags based on post content.

## Style Guidelines:

- Primary color: Vivid purple (#9400D3) to represent fantasy and magic.
- Background color: Very light purple (#F0E6FF), almost white, to provide a clean, uncluttered backdrop and support the dark color scheme.
- Accent color: Electric blue (#7DF9FF) to highlight interactive elements and create visual interest.
- Headline font: 'Poppins' (sans-serif) for a modern and fashionable feel.
- Body font: 'PT Sans' (sans-serif) paired with Poppins for body text to improve readability for longer text blocks.
- Use custom icons with a line art style.
- Subtle transitions and animations on user interactions.
